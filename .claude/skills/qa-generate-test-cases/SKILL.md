# Скилл: генерация тест-кейсов из User Story

## Назначение

По описанию пользовательской истории или требования подготовить тест-кейсы.

## Когда использовать

Пользователь прислал User Story, ТЗ или описание фичи и просит тест-кейсы.

## Шаги

1. Выделить тестируемые сущности, входные данные и ожидаемые результаты.
2. Найти неясные места и риски.
3. Составить позитивные и негативные сценарии.
4. Добавить проверки граничных значений и ошибок.
5. Оформить в формате, близком к TestRail:
   - ID
   - Название
   - Предусловия
   - Шаги
   - Ожидаемый результат
   - Приоритет

## Формат файлов

Сохранять в `work/test-cases/` по правилу нейминга из `CLAUDE.md`.
