# Скилл: выбор агента

## Назначение

Роутер определяет, какому субагенту передать запрос пользователя.

## Когда использовать

На любом входящем запросе, если не ясно, какой агент должен отвечать.

## Шаги

1. Прочитать запрос пользователя.
2. Определить доминирующую тему:
   - обучение, теория, курс, конспект — `learn-assistant`;
   - код, Python, Selenium, Playwright, pytest — `python-coder`;
   - тест-кейсы, баги, оценки, требования, чек-листы — `qa-assistant`;
   - Excel-спецификация, одновременно затрагивающая обязательные поля и значения по умолчанию — `parallel_orchestration`;
   - только обязательные поля в Excel-спецификации, required-параметры — `required-fields-validator`;
   - только значения по умолчанию, default value, дефолты параметров из Excel-спецификации — `default-values-validator`.
3. Если выбран `parallel_orchestration`:
   - уточнить у пользователя режим (последовательный или параллельный);
   - при параллельном режиме использовать `file://.claude/skills/router/parallel-orchestration/SKILL.md`;
   - при последовательном режиме сначала запустить `required-fields-validator`, затем `default-values-validator`.
4. Если тема смешанная или неясная — задать уточняющий вопрос.
5. Вернуть имя выбранного агента/режима и краткое обоснование.

## Пример

Запрос: «Объясни, что такое explicit wait в Selenium»
Выбор: `python-coder`, потому что запрос про конкретный инструмент и технику в коде.

Запрос: «Собери значения по умолчанию для параметров из МультиКарта_описание полей.xlsx»
Выбор: `default-values-validator`, потому что запрос про default value параметров Excel-спецификации.
