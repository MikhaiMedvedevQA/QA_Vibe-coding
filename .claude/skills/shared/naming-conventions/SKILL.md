# Общий скилл: правила нейминга файлов

## Назначение

Гарантировать единообразие имён файлов во всём проекте.

## Когда использовать

Любой агент перед созданием нового файла должен проверить имя по этому скиллу.

## Правило

```
[дата — опционально] — [тема] — [тип].md
```

- Дата: `YYYY-MM-DD`, только для датированных артефактов.
- Разделитель: ` — ` (длинное тире с пробелами).
- Тема: краткое описание на русском.
- Тип: суффикс по назначению и папке.

## Типы по папкам

- `templates/` — `template`
- `work/test-cases/` — `tc`
- `work/bug-reports/` — `bug`
- `work/api/` — `api`
- `work/exploratory/` — `exploratory`
- `work/environments/` — `env`
- `references/` — `ref`
- `learn/python|selenium|playwright/` — `notes` / `exercise` / `project`
